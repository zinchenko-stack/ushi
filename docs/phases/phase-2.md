# Phase 2 — Базовый UI Проектов (без external-папок)

**Перед началом:** прочитай `docs/projects-brief.md`, особенно §6 (UI), §7.1 (3 пути старта), §8 (слои кода).

## Что нужно сделать

Заменить текущий главный экран на двухпанельную компоновку с sidebar-аккардеоном Проектов и секцией «Записи». Добавить создание, переименование, удаление Проектов. Move записи между Проектами. Все Проекты в этой фазе — только **managed** (в `Application Support/UshiNext/Projects/{id}/`).

## Контекст

После Phase 1 у нас есть `ProjectStore` и расширенная `RecordingsStore`. UI пока старый (показывает плоский список). Нужно его переделать.

## Задачи

1. **Главное окно — двухпанельная компоновка.** `NavigationSplitView` или `HSplitView`. Слева sidebar 250px, справа — детали выбранной записи.
2. **SidebarViewModel.** Подписывается на `ProjectStore`, отдаёт:
   - `pinnedAndSortedProjects: [Project]`
   - `recentRecordings(in: Project?) -> [Recording]` — лимит 5 по умолчанию
   - `orphanRecordings(limit: Int) -> [Recording]`
   - флаги раскрытости каждой секции (хранить в `@AppStorage` или просто в State)
3. **SidebarView.**
   - Сверху: большая кнопка «Начать запись» (старт в orphan, с `app.lastUsedPreset`). Под ней мелкий chip с текущим пресетом.
   - Поиск (placeholder, в Phase 4 заполним функционал — пока просто UI).
   - Секция `── Проекты ──`. Каждый Проект — раскрываемая строка с DisclosureGroup. По умолчанию раскрыт.
     - Строка Проекта: иконка folder, имя, на hover справа `⏺` и `⋯`.
     - Раскрытые: 5 последних записей с relative time («2ч», «1д»). Под ними «Показать больше →».
   - Секция `── Записи ──` (orphan). По умолчанию раскрыта. Те же 5 записей + «Показать больше».
   - Внизу: «⚙ Настройки» (заглушка).
4. **Hero-стейт.** Когда ничего не выбрано в sidebar (или приложение только открылось) — главная область показывает hero:
   - Заголовок «Начать запись».
   - Два chip: `[🎙 Микрофон ▾]` (пресет) и `[Без проекта ▾]` (целевой Проект). Dropdowns меняют значение перед стартом.
   - Большая кнопка ●.
   - Если выбран Проект — chip-пресета подтягивается из `project.lastUsedPreset`.
5. **Детальный экран записи.** Когда выбрана запись — показывает плеер, транскрипт (если есть), название, кнопку «Показать в Finder». Можно переиспользовать существующий `RecordingView` из текущего Ushi с минимальной адаптацией.
6. **Создание Проекта — модалка (только managed).**
   - Sheet с заголовком «Новый проект».
   - Поле «Название».
   - Радио «Что записываем»: микрофон / системный + микрофон / экран.
   - Радио «Где хранить»: **только «Создать в Ushi»** активно в этой фазе. «Использовать существующую папку» — disabled с подсказкой «Скоро».
   - Кнопки Отменить / Создать.
7. **Контекстное меню Проекта (⋯ или right-click).** 4 пункта:
   - Закрепить / Открепить
   - Показать в Finder (`NSWorkspace.activateFileViewerSelecting`)
   - Переименовать (inline в sidebar — заменить Text на TextField)
   - Удалить… → открывает диалог удаления
8. **Диалог удаления Проекта.**
   - Заголовок «Удалить «N»?»
   - Подзаголовок с числом записей и размером.
   - Чекбокс «Удалить также записи (X МБ)», по умолчанию выкл.
   - Если выкл — после удаления `ProjectStore.delete(project, deleteRecordings: false)`, записи в БД переезжают в orphan (`projectId = nil`).
   - Если вкл и размер > 500 МБ — typed confirm (введи имя проекта для подтверждения).
9. **Контекстное меню Записи.** Пункты:
   - Переместить в → подменю со списком Проектов + «Без проекта» + «Создать проект…».
   - Переименовать (inline).
   - Показать в Finder.
   - Удалить.
10. **Move to между Проектами.** Файл физически переезжает: `FileManager.moveItem` из `Projects/{old}/recordings/` в `Projects/{new}/recordings/` (или в `Recordings/` для orphan). Поскольку в Phase 2 всё managed — это всегда один том, всегда мгновенно. Обнови `recording.fileURL` и `projectId` в БД.
11. **Старт записи в Проект через ⏺.** Клик по ⏺ у Проекта в sidebar → стартует запись с `project.lastUsedPreset`, файл сохраняется в `Projects/{id}/recordings/`. После остановки — `project.lastUsedPreset` обновляется (на случай если в hero перед стартом поменяли).

## Готово когда

- Sidebar показывает Проекты аккардеоном + Записи (orphan).
- Можно создать Проект, переименовать, закрепить, удалить (с/без файлов).
- Можно записать в orphan (главная кнопка) и в Проект (⏺).
- Move to работает между всеми Проектами и orphan.
- Hero показывается на пустом стейте, chip-ы меняют пресет и target.
- Никаких регрессий старого функционала записи.
