# Phase 4b — Умные названия записей (маленькая локальная модель)

**Перед началом:** прочитай `docs/projects-brief.md` (§7.3 авто-имя, §9 про локальный LLM и сервис `Summarizer`). Работаем только в `ushi-next/`, текущий `ushi/` не трогаем.

## Зачем

Сейчас (Phase 4) название записи — первая осмысленная фраза транскрипта (`ushi-next/AutoTitle.swift`). Пользователь хочет **суть разговора** в 3–7 словах. Пример на реальном транскрипте про падение поддержки помощи Украине в Европе:

- сейчас: «Читает заголовки и видит, как из его кармана уже пятый год вынимают…»
- хотим: «Европа устаёт от помощи Украине»

## Ограничения (решены с пользователем, не пересматривать)

- **Всё локально, без интернета и облачных API** — записи приватные (психолог, встречи).
- **Модель ≈ 0,5 ГБ** (максимум ~1 ГБ, только если 0,5 ГБ явно не справляется). 2,5 ГБ — отказ.
- **Встроенная модель Apple (FoundationModels) не подходит:** не поддерживает русский, и Apple Intelligence не включается при русском языке macOS (проверено: `supportedLanguages` без `ru`, `availability = appleIntelligenceNotEnabled`).
- Модель **необязательная**: скачивается только если пользователь включил «Умные названия» в Настройках. Без неё остаётся текущий `AutoTitle` (первая фраза) — это fallback, его не удалять.

## Шаг 1 — выбрать модель (до кода!)

1. Скачать официальный релиз llama.cpp для macOS arm64 с github.com/ggml-org/llama.cpp/releases (нужен `llama-cli` / `llama-completion`).
2. Скачать 2–3 кандидата GGUF (Q4_K_M) с Hugging Face: семейства Qwen (0.5B–1.5B), Gemma (≈1B), по возможности русскоязычные дообучения (Vikhr). Искать самые свежие на момент работы.
3. Прогнать на транскриптах из `~/Library/Application Support/UshiNext/transcripts/*.txt` с промптом вида:
   «Придумай короткий заголовок (3–7 слов) к этой записи разговора. Только заголовок, без кавычек и точки. Текст: …»
   Брать первые ~2000 символов транскрипта.
4. Показать пользователю таблицу: модель · размер · заголовки. **Решение о модели принимает пользователь.**

## Шаг 2 — встроить (после выбора)

По образцу whisper-интеграции, которая уже есть:

- **Бинарь:** собрать llama.cpp как `vendor/llama.cpp` (git submodule, как `vendor/whisper.cpp`) и класть CLI в бандл так же, как `whisper-cli` (см. `scripts/build-whisper.sh`, `ushinext.xcodeproj` — ссылка на `vendor/whisper.cpp/build/bin/whisper-cli`). Metal включить.
- **Загрузка модели:** по образцу `ushi-next/ModelManager.swift` (докачка, возобновление, прогресс, хранение в `~/.ushi/models/`). Отдельное состояние для модели названий — не смешивать с whisper-моделью.
- **Сервис `Summarizer`** (`ushi-next/Summarizer.swift`, имя из §9 брифа): `func title(for transcript: String) async -> String?`. Запуск CLI как `Process` по образцу `TranscriptionService.swift`, таймаут ~30 с, пост-обработка (убрать кавычки/точку, обрезать до 80 символов, заглавная буква). Любая ошибка → `nil`.
- **Где вызывать:** `RecordingsStore.applyAutoTitle` (сейчас там `AutoTitle.make`). Логика: если модель готова — `Summarizer`, иначе/при `nil` — `AutoTitle.make`. `titleSource = .auto`. Ручные названия (`.manual`) никогда не трогать.
- **Настройки:** в `SettingsView.swift` переключатель «Умные названия» + размер скачивания + прогресс.
- Работа в фоне, UI не блокировать. Модель грузить на время генерации и выгружать (процесс CLI завершается).

## Как собирать и проверять

- Сборка (сертификат команды на этом Mac отсутствует, используется локальный):
  `xcodebuild -project ushinext.xcodeproj -scheme UshiNext -configuration Debug -destination 'platform=macOS' -derivedDataPath build/DerivedData CODE_SIGN_IDENTITY="UshiNext Local Signing" CODE_SIGN_STYLE=Manual DEVELOPMENT_TEAM= build`
  Не менять настройки подписи в `project.pbxproj`.
- Тесты: `cd ushi-next-tests && swift test` (исходники подключены симлинками в `Sources/UshiNextCore`). Добавить тест пост-обработки ответа модели.
- Ветка: `phase-2-projects-ui` (или новая от неё). Коммиты по-русски, как в истории.

## Общение с пользователем

Пользователь не технарь: коротко, только результат, проблемы и что нужно от него. Каждое скачивание (llama.cpp, модели) — спросить разрешение, указать размер.

## Готово когда

- При включённых «Умных названиях» новая запись после расшифровки получает заголовок по сути (3–7 слов).
- Без модели всё работает как сейчас (первая фраза).
- Ручное переименование не перезаписывается.
- Скачивание модели можно прервать и продолжить.
