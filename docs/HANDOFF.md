# Передача работы: UshiNext (состояние на 2026-09-29)

Прочитай целиком перед началом. Затем `docs/projects-brief.md` (особенно §0, §6–§8, §11, §13).

## Что это

Ushi — macOS-приложение: запись созвонов/лекций (системный звук, микрофон, экран) и локальная расшифровка через whisper.cpp. Рядом с рабочим `ushi/` сделана новая сборка **UshiNext** (`ushi-next/`, `ushinext.xcodeproj`) с Проектами. **`ushi/` не трогать** — им пользуются каждый день.

- Ветка: `phase-2-projects-ui` (запушена в `origin`, `main` не трогали). Работай в ней.
- Коммиты — по-русски, в стиле истории. Автор в репо уже настроен (zinchenko-stack).

## Сборка и тесты

- Сборка (сертификата команды `SF8JAMK5ZA` на этом Mac нет — используется локальный самоподписанный, **настройки подписи в pbxproj не менять**, иначе macOS будет сбрасывать разрешение «Запись экрана» после каждой сборки):
  ```
  xcodebuild -project ushinext.xcodeproj -scheme UshiNext -configuration Debug -destination 'platform=macOS' -derivedDataPath build/DerivedData CODE_SIGN_IDENTITY="UshiNext Local Signing" CODE_SIGN_STYLE=Manual DEVELOPMENT_TEAM= build
  ```
  Приложение: `build/DerivedData/Build/Products/Debug/UshiNext.app`. Перезапуск: `pkill -x UshiNext; open <app>`.
- Тесты: `cd ushi-next-tests && swift test` (26 тестов, все зелёные). Исходники подключены симлинками в `Sources/UshiNextCore`; новые чистые (без UI) файлы подключай так же.
- В таргете `SWIFT_DEFAULT_ACTOR_ISOLATION = MainActor` — тяжёлую работу явно уводи в фон (`@concurrent`, `Task.detached`, `nonisolated`).

## Задача 1 — проверить всё и починить

Пройди чек-лист. То, что можно проверить без рук пользователя (сборка, тесты, логика, файлы на диске, база `~/Library/Application Support/UshiNext/store.sqlite`), — проверь сам. UI-шаги попроси сделать пользователя **по одному-два за раз**, коротко.

1. Перенос из старого Ushi: 34 записи появились в «Записях», у каждой открывается текст, аудио проигрывается (у 2 аудио удалено ещё в старом Ushi — это норма). Старый `~/Library/Application Support/ushi/` не изменился. Повторный перенос не создаёт дублей.
2. Menu bar: «Начать запись», «Записать в проект → X», «Источник» (галочки синхронны с окном), таймер у иконки во время записи, «Остановить».
3. Загрузка аудио: mp3/m4a → появляется в выбранном проекте → расшифровка → авто-название. Неподдерживаемый файл → понятная ошибка.
4. Регресс: запись без проекта и в проект, перенос записи, удаление проекта (с файлами и без), поиск.
5. Всё найденное — чинить, пересобирать, коммитить маленькими коммитами, пушить.

## Задача 2 — открытые пункты (после проверки, по согласию пользователя)

- **Мягкие разрешения на запись** (важно до раздачи друзьям). Сейчас любая запись идёт через ScreenCaptureKit, и macOS показывает пугающее окно «обход системного инструмента выбора окон… доступ к экрану». Нужно: аудио через Core Audio process taps (разрешение «Только запись системного звука», macOS 14.4+), микрофон через AVAudioEngine, экран — только при включённой кнопке «Экран». Ниже 14.4 — старый путь. Это переделка `AudioRecorder.swift`; писатель (`RecordingWriter`, сведение источников) можно переиспользовать.
- **Умные названия** — `docs/phases/phase-4b-smart-titles.md`. Идёт расширенный тест Gemma-3-1B / Qwen3-1.7B на 8 текстах. Встраивать, только если модель ловит суть ≥ 6 из 8 и пользователь согласен.
- **Финал (§10 Phase 6, п. 4)**: когда пользователь скажет, что UshiNext его устраивает, — переименование в Ushi (`AppContainer.name`, bundle id, иконка), релизная сборка (`scripts/build-release-dmg.sh`), решение по подписи для раздачи. Не начинать без явного «да».

## Решения, которые не пересматривать

- Всё локально, никаких облачных API (записи приватные: психолог, встречи).
- Встроенная модель Apple (FoundationModels) не подходит: нет русского, Apple Intelligence не включается при русском языке macOS.
- Модели > ~1 ГБ для названий — нет.
- По умолчанию записывается «Системный звук + Микрофон».
- Экран-блокировку «нужен доступ к записи экрана» убрали намеренно — разрешение просит macOS при первой записи.
