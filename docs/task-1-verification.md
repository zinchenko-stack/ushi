## Исправлено

1. Подготовка WAV больше не удаляет входной WAV и не перезаписывает соседний файл. Используется отдельная временная папка.
2. Одинаковые имена аудио в разных проектах больше не перезаписывают расшифровки друг друга.
3. Импорт из старого Ushi больше не считает неудачное копирование успешным переносом; можно повторить. Совпадающие имена текстов получают отдельные файлы; частично скопированные данные убираются при ошибке.
4. Удаление проекта останавливается, если запись не удалось перенести. Удаление проекта с текущей записью блокируется.
5. Повреждённое аудио отклоняется до добавления в список.
6. Ожидающая расшифровка использует фактическое расположение файла через bookmark; статус расшифровки синхронизируется с состоянием записи.
7. «Создать проект…» в меню открывает создание проекта; ошибки начала записи из меню показываются сразу.
8. После сообщения пользователя о замирании таймера при открытом меню таймер переведён в common run-loop modes. Сохранённая длительность считается по времени начала. Повторное подтверждение в интерфейсе ещё ожидается.
9. Проверка отмены переноса больше не зависит от гонки с задержкой 5 мс: отмена выполняется после начала копирования.
